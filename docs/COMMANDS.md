# Commands and permissions

## Commands

| Command | Description | Permission | Usage |
|---------|-------------|------------|-------|
| `/thanks` | Appreciation Token stats and admin issue/redeem | `` | `/thanks / /thanks give <player> <amount> / /thanks redeem <amount>` |
| `/bonus` | Claim daily Appreciation Token streak bonus | `` | `/bonus` |

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `rootappreciation.use` | Use /thanks and /bonus | `true` |
| `rootappreciation.admin` | Give Appreciation Tokens and reload | `op` |
| `rootappreciation.redeem` | Redeem Appreciation Tokens (when redeem targets exist) | `true` |
